# ⚡️ Power Struggle（パワーストラグル）

[English](README.md)

**USB-C でつないだ 2 台のスマホで、相手のバッテリーを物理的に奪い合う 2 人対戦の連打バトル。**

2 台のスマホを USB-C ケーブルでつないで連打。勝っている側が本当に充電され、負けている側のバッテリーは本当に減っていきます。「2 人ともバッテリー残り 5%、このままでは 2 人とも家までもたない。でもどちらかが相手の電池をもらえば 1 人は助かる」という状況のためのアプリです。

📖 プロジェクトページ: **[kenkawamoto.com/projects/power-struggle](https://kenkawamoto.com/projects/power-struggle)**

## 遊び方

- 2 台のスマホを**お尻（充電口側）同士を向かい合わせて**テーブルに置き、ケーブルでつなぎます。プレイヤーはそれぞれ自分のスマホの向こう側に座ります（そのため画面は上下逆さまに表示されます）。
- 画面のどこでもタップすると、エネルギーの流れの上にある「結び目」が自分のバッテリー側に引き寄せられます。手を止めると、結び目はケーブル側へ自然に戻っていきます。
- 結び目がケーブルのすぐ先にある線を越えると電力の向きが切り替わり、自分のスマホが充電されます。スマホのステータスバーに出る充電マークが、本当に充電されている証拠です。
- 速く連打するほど、相手のバッテリーを多く奪えます。負けると本当にバッテリーが減ります。

相手の機器でアプリが動いていない場合（アプリ未インストール、または iPad / iPhone）は、1 台のスマホの画面を上下に分けて 2 人で対戦します。この場合も電力のやり取りは本当に行われます。

## 自分で試してみる

パソコンは不要です。初回の準備は 10 分ほどで、作業はほぼ 1 台のスマホだけで済みます。

### 必要なもの

- **スマホ A（「ホスト」になるスマホ）:** Android 13 以降の Android スマホ。実際に電力の向きを切り替えるのはこのスマホです。動作確認は Google Pixel のみで、他社のスマホでは動かない可能性があります。
- **対戦相手の機器 B**（以下のどれか）:
  - USB-C 端子のある Android 13 以降の Android スマホ（2 人それぞれが自分の画面で遊べます）
  - iPad、USB-C の iPhone（iPhone 15 以降）、または古い Android スマホ。これらではアプリが動かないため、スマホ A の画面を分けて 2 人で遊びますが、電力のやり取りは本当に行われます。
- **データ通信に対応した USB-C ⇔ USB-C ケーブル。** 最近のスマホに付属しているケーブルなら使えます。安価なケーブルの中には充電専用のものがあり、それでは動きません。
- 準備中、スマホ A が **Wi-Fi** につながっていること。

### ステップ 1: アプリをインストールする

スマホ A で行います。機器 B が Android スマホなら、B でも同じように行います。

1. スマホで **[ダウンロードページ](https://github.com/kenkawakenkenke/power-struggle/releases/latest)** を開き、**Assets** の下にある **.apk** で終わるファイルをタップしてダウンロードします。
2. ダウンロードしたファイルを開きます（ダウンロード完了の通知、または **Files** アプリの「ダウンロード」から）。
3. 初回は「このブラウザからのアプリのインストールは許可されていません」と表示されます。**設定** をタップして **この提供元のアプリを許可** をオンにし、元の画面に戻ります。
4. **インストール** をタップします。Google Play プロテクトから「不明なアプリ」という警告が出た場合は、**詳細** → **インストールする** をタップします（Play ストア以外から入手したアプリなので警告が出ます）。

### ステップ 2: Shizuku を準備する（スマホ A のみ）

どちらのスマホが充電する側になるかの切り替えは、本来パソコンからしかできません。**Shizuku** という無料アプリを使うと、Power Struggle がスマホ単体でそれを行えるようになります。機器 B には不要です。

1. **Shizuku をインストールします。** [Google Play ストア](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api) から入手できます。
2. **開発者向けオプションをオンにします。** **設定** → **デバイス情報** を開き、**ビルド番号** を 7 回続けてタップします。PIN の入力を求められたら入力します。「これでデベロッパーになりました」と表示されれば完了です。
3. **Shizuku をペア設定します。**
   1. Shizuku を開き、「**ワイヤレスデバッグ経由で起動**（Start via Wireless debugging）」の下にある「**ペアリング**（Pairing）」をタップします。通知の許可を求められたら許可します。
   2. **設定** → **システム** → **開発者向けオプション** → **ワイヤレス デバッグ** を開き、オンにします（確認画面が出たら許可します）。
   3. 「**ペア設定コードによるデバイスのペア設定**」をタップすると、6 桁のコードが表示されます。
   4. 画面上端から通知を引き下ろすと、Shizuku の通知にコードの入力欄があります。そこにコードを入力して送信します。「ペアリングに成功しました」と表示されれば完了です。
4. **Shizuku を起動します。** Shizuku に戻り、「ワイヤレスデバッグ経由で起動」の下の「**開始**（Start）」をタップします。Shizuku の画面上部に「**Shizuku は実行中です**（Shizuku is running）」と表示されれば準備完了です。

ペア設定は最初の 1 回だけです。ただし**スマホを再起動すると Shizuku は止まる**ので、そのときは Wi-Fi がつながった状態で Shizuku を開き、もう一度「開始」をタップしてください（うまくいかない場合は、先に「ワイヤレス デバッグ」をもう一度オンにします）。

困ったときは、画面写真付きの Shizuku 公式ガイドも参考になります: [shizuku.rikka.app/guide/setup](https://shizuku.rikka.app/guide/setup/)

### ステップ 3: 遊ぶ

1. スマホ A で Power Struggle を開きます（機器 B が Android スマホでアプリを入れた場合は、B でも開きます）。
2. 2 台をお尻同士を向かい合わせてテーブルに置き、ケーブルでつなぎます。
3. 表示される確認画面を許可します（初回のみ）:
   - スマホ A では、**Power Struggle が Shizuku を使うことを許可**（「**常に許可**」を選択）し、続いて **USB デバイスへのアクセスを許可** します（「常に開く」のチェックがあればオンにして **OK**）。
   - 機器 B では、USB アクセサリについて **Power Struggle を開くことを許可** します。
4. 数秒で画面に **CHARGING**（充電中）または **DRAINING**（放電中）と表示されます。連打開始！

### うまくいかないときは

- **「Connect the other phone」のまま変わらない:** ケーブルを抜いて、もう一度差し込んでください。それでもだめなら別のケーブルを試してください。充電専用のケーブルの可能性があります。
- **スマホ A が電力を切り替えない:** Shizuku を開き、「Shizuku は実行中です」と表示されているか確認してください。準備のあとにスマホを再起動した場合は、もう一度「開始」をタップします。
- **2 台とも Android で、両方で Shizuku が動いている:** Shizuku を動かすのは 1 台だけにしてください。機器 B の Shizuku を止めます（または再起動後に開始しないでおきます）。
- **バッテリー残量がとても少ないスマホが電力を送らない:** 残量がほぼない状態では、電力の供給を拒否するスマホがあります。少し充電してから試してください。

### 遊んだあとは

- **元に戻すには:** Power Struggle と Shizuku をアンインストールし、**設定** → **システム** → **開発者向けオプション** で **ワイヤレス デバッグ** をオフにします（または一番上のスイッチで開発者向けオプションごとオフにします）。
- **バッテリーに悪くない？:** 普段の使い方と変わりません。スマホ間に流れる電力は約 4.5 W で、普通の充電器より穏やかです。ただし負けた側は本当にバッテリーが減るので、電池を残しておきたいスマホでは遊ばないでください。

## 仕組み

**充電する側・される側の入れ替え。** 最近のスマホの USB-C 端子は、電力を送る側（ソース）にも受け取る側（シンク）にもなれます。2 台をつなぐと USB Power Delivery という規格がどちらがどちらになるかを決めますが、この規格ではケーブルを抜かずに途中で役割を入れ替える「パワーロールスワップ」もできます。Android の USB 設定にある「接続したデバイスを充電する」もこの仕組みを使っています。Power Struggle はゲームの中から、次のコマンドで同じ入れ替えを行います。

```
dumpsys usb set-port-roles <port> <source|sink> <host|device>
```

このコマンドにはシェル（adb）レベルの権限が必要なので、アプリは [Shizuku](https://shizuku.rikka.app/) を通じて実行します。Shizuku はアプリに adb シェルと同じ権限を貸してくれるツールで、root 化は不要です。これが必要なのは 1 台だけです。入れ替えは 2 台の間で取り決められ、もう 1 台は要求を受け入れるだけだからです。入れ替えには約 0.5 秒かかり、その後は約 4.5 W（Pixel の場合 5 V・0.9 A）が逆向きに流れます。

**同じケーブルでゲームのデータも送る。** Shizuku が動いているスマホが USB の「ホスト」になり、相手のスマホを [Android Open Accessory](https://source.android.com/docs/core/interaction/accessories/protocol) モードに切り替えます。もともとはカーナビやドックのための仕組みですが、これにより 2 台の間にミリ秒単位の遅延で通信できる直通のデータ回線ができ、タップやゲームの状態をやり取りできます。USB では電力の役割とデータの役割は独立しているので、電力の向きが何度入れ替わってもデータ回線は切れません。

**画面はうそをつかない。** 各スマホの「充電中 / 放電中」の表示は、ゲームのメッセージではなく、そのスマホ自身のバッテリーの実測値（`BatteryManager`）から作っています。画面に出ているのは、バッテリーで実際に起きていることです。

Pixel 9 Pro XL ⇔ Pixel 4 XL での実測では、電力を送る側のバッテリーは約 1500 mA で減る一方、受け取る側のバッテリーは約 400 mA しか増えません。約 4.5 W のうちかなりの部分を 2 台の画面とアニメーションが消費してしまうので、使うのは本当に困ったときだけにしてください。

## 現状と注意点

これは試作品で、動作確認は Pixel（と iPad との対戦）でのみ行っています。

- `dumpsys usb set-port-roles` はデバッグ用の機能で、公開 API ではありません。他社製のスマホや今後の Android のバージョンでは使えない可能性があります。
- バッテリー残量が少ないと電力を送らないスマホがあります。また、アプリ側ではまだ「残量がこれ以下なら止める」という下限を設けていません。電池を残しておきたいスマホでは遊ばないでください。
- iPad / iPhone は USB でアプリと通信できない（Android Open Accessory に対応していない）ため、1 台モードで電力だけをやり取りする対戦相手になります。

## ソースからビルドする

開発者向けです。JDK 17 以降と Android SDK が必要です。

```sh
./gradlew installDebug      # デバッグ版をビルドして、接続中のスマホにインストール
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk をビルド
```

`~/.gradle/gradle.properties` に `POWER_STRUGGLE_STORE_FILE`、`POWER_STRUGGLE_STORE_PASSWORD`、`POWER_STRUGGLE_KEY_ALIAS`、`POWER_STRUGGLE_KEY_PASSWORD` を設定するとリリース版が署名されます。設定がない場合、リリース版の APK は署名なしになります。
